Privacy Policy

Last updated: July 30th, 2026

This Privacy Policy describes how bmrb_extract ("Service") handles user data.

1. Data Collection

The Service collects:

  • Uploaded files (temporarily)
  • Technical metadata (e.g., IP address, timestamps)
  • Optionally, personal data (e.g. email address, conversation with annotators)
2. Purpose of Processing

The Service processes the data for:

  • Data conversion and validation
  • System monitoring and security
  • User support (if requested)
3. Data Retention

All data will be automatically deleted once its scheduled expiration date has passed ({{ SUCCESS_VALIDITY_PERIOD_IN_DAYS }} days since the last successful conversion, {{ FAILURE_VALIDITY_PERIOD_IN_DAYS }} days since the last failed conversion or unprocessed).

4. Data Sharing

No intentional sharing with third parties by default. However, individual users can share tokenized URLs to access user data and processed data for co-authors.

5. User Responsibility

Users must avoid uploading sensitive personal data and sharing the tokenized URLs unless necessary.
