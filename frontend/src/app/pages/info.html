Welcome to bmrb_extract

bmrb_extract is an NMR data conversion service that simplifies data deposition to PDB (via OneDep) and BMRB (via BMRBdep) by creating a single NMR experimental data file from various software native formats.

Steps for file conversion
  • You should read "Terms and Conditions" and "Privacy Policy" and must accept our policies by clicking the check-box below
  • In a Upload files page, select target deposition system and upload files, and choose the appropriate format for each
  • In case the requirements matches, conversion starts when you select "Process selected files" button
  • After analysis of upload files, you can overview conversion status ("OK", "Warning", or "Error") and diagnostic messages if necessary on Upload summary page
  • In case of "Warning" status, you must accept all warnings to access the conversion results, otherwise you should re-upload corrected files
  • In a Download, you can view statistics of the data conversion and access to a zipped conversion results file
  • Once you download the conversion results, you will no longer be able to re-upload files (create new session if necessary)
  • You will see tokenized URL to review the session (read-only) until scheduled expiry date
  • When you need assistance in data conversion, please contact us only through a Help desk page, do not to send email directly
  • Your mail address must be verified before using the Help desk
  • You can log-in with the verified mail and access to all your previous conversion sessions from the top-bar menu
Requirements for OneDep deposition
  • Coordinate file (PDBx/mmCIF or legacy PDB format)
  • Assigned chemical shift file (NMR-STAR, NEF, existing BMRB ID, or other supported formats)
  • Restraint file (Software-native format)
  • Spectral peak list file (Software-native format)
Requirements for ongoing OneDep deposition - Replacing assigned chemical shifts
  • Coordinate file (PDBx/mmCIF or legacy PDB format)
  • Master NMR data file (NMR-STAR or NEF) containing at least assigned chemical shifts and restraints
  • Assigned chemical shift file (NMR-STAR, NEF, existing BMRB ID, or other supported formats)

Assigned chemical shifts of the master file will be replaced with the chemical shifts from the newly uploaded files.

Requirements for BMRBdep deposition
  • Assigned chemical shift file (NMR-STAR, NEF, or other supported formats)
  • Other NMR experimental data in NMR-STAR format except for restraints
