Welcome to bmrb_extract

bmrb_extract is an NMR data conversion service that simplifies data deposition to PDB (via OneDep) and BMRB (via BMRBdep) by generating a single NMR data file from various software native formats.

Please see Preface for information about the origin of the service.

Steps for NMR data conversion
  • You must read Terms and Conditions and Privacy Policy and agree to these policies by clicking check-box below before file upload
  • In an Upload files page, select target deposition system and upload files, and choose the appropriate format for each
  • In case the requirements matches, conversion starts when you select "Process selected files" button
  • After analysis of upload files, you can overview conversion status ("OK", "Warning", or "Error") and diagnostic messages if necessary on an Upload summary page
  • In case of "Warning" status, you must accept all warnings to access the conversion results, otherwise you should re-upload corrected files
  • In a Download, you can view statistics of the data conversion and access to a zipped conversion results file
  • Once you download the conversion results, you will no longer be able to re-upload files (create new session if necessary)
  • You will see tokenized URL to review the session (read-only) until scheduled expiry date
  • When you need assistance in data conversion, please contact us only through a Help desk page, do not send us email directly
  • Your mail address must be verified before using the Help desk
  • You can log-in with the verified mail and access to all your previous conversion sessions from icon of the top-bar menu
Requirements for OneDep deposition
  • Coordinate file (PDBx/mmCIF or legacy PDB format)

    • As to conventional separated file deposition

    • Assigned chemical shift files (NMR-STAR V3, NEF, other supported formats, or existing BMRB ID)
    • Restraint files (Software-native format)
    • Optionally, spectral peak list files (Software-native format)
    or

    As to combined single file deposition

    • NMR unified data file (NMR-STAR V3 or NEF) containing assigned chemical shifts and restraints

The wwPDB NMR Validation Task Force strongly encourages the submission of spectral peak lists, in particular those generated from NOESY spectra.

Requirements for ongoing OneDep deposition

Replacing assigned chemical shifts

  • Coordinate file processed by OneDep (PDBx/mmCIF)
  • NMR unified data file processed by OneDep (NMR-STAR V3) containing assigned chemical shifts and restraints.
  • Correct assigned chemical shift files (NMR-STAR V3 formats).

The chemical shifts in the NMR unified data file will be replaced with those in the correct assigned chemical shift file(s).

Requirements for BMRBdep deposition

BMRB Only

  • Assigned chemical shift files (NMR-STAR, NEF, or other supported formats)
    • Optionally
  • Other data files in NMR-STAR V3 format (e.g. relaxation, kinetic, thermodynamic parameters)
  • Topology file, which describes a molecular assembly (a complete sequence of molecules and ligands) and is used when it is not in the primary data file
