Preface

NMR experimental data used for structure determination typically include assigned chemical shifts, restraints, and optionally spectral peak lists. The Worldwide Protein Data Bank (wwPDB) requires the mandatory submission of assigned chemical shifts and restraints for PDB depositions.

Assigned chemical shifts must be provided in NMR-STAR V3 format, the primary format for both the PDB Core Archive and the BMRB Core Archive. Restraints and spectral peak lists, on the other hand, have traditionally been accepted in their original software native formats. To realize the FAIR principle with respect to structural data, metadata, and experimental data used for the NMR structure determination, the OneDep system has been extended to support these native formats and convert them to the NMR-STAR V3 format.

Converting all NMR experimental data into a single, standardized format offers several advantages:

  1. Data consistency – Annotators can review and correct data without needing to understand software native formats and their software-specific conventions
  2. Validation – Standardized data enables validation tools to assess the agreement between experimental restraints and the resulting structure model
  3. Simplified distribution – A unified data format allows database providers to distribute NMR data in a single file
  4. Interoperability – Researchers can more easily test whether a structure model can be reproduced using the standardized data

The NMR data processing package in the OneDep system currently supports 12 restraint file formats and 11 spectral peak list file formats that are sufficient to cover all existing PDB entries. Ideally, all software developers involved in NMR data analysis and structure determination should adopt community-standard formats, such as NMR-STAR V3 or NMR Exchange Format (NEF). However, due to the diversity and complexity of NMR data, the OneDep system and PDB annotators still face significant challenges in handling and troubleshooting of non-standard data files. In addition, the OneDep release cycle is coupled with NMR specific bug fixes, so depositors in trouble often have to wait for the next release of the OneDep system, which usually happens every month.

To streamline the deposition process and reduce the workload for PDB annotators, a standalone NMR data conversion service is being planned. This service aims to improve the overall experience for PDB (NMR structure containing biological macromolecules) and BMRB depositors (NMR experimental data only), as well as for the annotators supporting both deposition systems.
